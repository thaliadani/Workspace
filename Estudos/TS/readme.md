# Configuração do TypeScript

1. Inicializar um projeto Node.js: npm int | npm init -y

2. Instalar o TypeScript
    2.1. Instalação global(não recomendado): npm install -g typescript
    2.2. Instalação local dentro do repositório(projeto): npm install typescript -D

3.Inicializar todas as configuracoes no projeto: npx tsc --init

4.Compilar ts e converter para js: npx tsc --watch
